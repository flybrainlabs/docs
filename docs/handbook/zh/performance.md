# 性能与图形显示

挖矿界面报告实际每秒神经更新、工作进度和日志。这些指标帮助调整会话，但不衡量生物预测准确性，也不独立决定报酬。

## 空闲、测量中与实际速率

未运行会话显示**未运行**，并隐藏每秒更新单位。已启动但尚无有效样本时显示**测量中**。只有计算池提供真实有限测量值时，才显示数值与**神经更新/s**。测得的零不同于数据缺失；历史平均值另行标注。

最初有限计划的两个已付款单位完成后，该计划没有开放轮次；单独的新阶段已登记新增目标。先连接钱包进入挖矿，再查看当前任务与预算状态。钱包连接不会生成吞吐量样本或新的付费任务。

## 模型时间与现实耗时

登记的基线步长代表 1 ms 模型时间。256 步轨迹代表模型中的 256 ms，与设备实际计算耗时无关。现实耗时单独测量。

吞吐量受线程数、内存带宽、浏览器调度、温度和后台活动影响。只应比较模型、任务范围及必需背景数量一致的运行。

## 合理调整线程

先选择适合可用资源的线程设置，观察内存、响应和进度。增加并发可能提升吞吐量，直到共享内存或调度成为瓶颈。更多线程也会与 3D 和浏览器其他工作竞争。

重大资源调整前保存检查点。省略必需背景的快速试验不等于完整计算。数值优化必须保持冻结输出契约。

## 使用 3D 视图

黑白视图采用竖形框架展示大脑和下方神经上下文，开启时中心缓慢旋转。显示设置汇总在顶部控件。可独立关闭图形，让会话专注计算。

解剖结构、当前计算观测和历史采样是不同视图。来源骨架不表示所有细胞活动，显示采样不替代完整科学输出。

## 渲染失败时

使用图形重试或关闭图形，保留错误并对照[神经元图谱](/atlas/)。图谱是有用的结构对照页面，但有独立浏览路径。图谱显示成功本身不证明完整模型计算与 3D 并行性能。

不要为修复 WebGL 或显示资源错误清除模型缓存。针对性诊断见[故障排查](/docs/troubleshooting/)。

## 设备验收

公开 WebGL 与模拟视口检查已通过。安卓 Chrome 真机、物理 GPU、低内存设备、更高并发、公开 512 步工作以及完整计算与 3D 并行仍需实际验收记录。

报告应包含浏览器版本、设备、已知可用内存、线程设置、图形模式、任务或轮次，以及实际停止阶段。记录针对性重试后同一保存工作能否恢复。模拟移动视口不能证明物理设备支持。
