# 项目概览

flybrainwork 将果蝇神经连接组数据转化为明确范围内的确定性计算。参与者可以准备模型、在冻结规则下搜索、保存可恢复成果，并提交符合条件的候选供完整复算。研究者可以浏览解剖结构和获准公开的证据，无需加入竞争。

## 主要产品入口

[挖矿](/mining/)是显式的计算流程。[神经元图谱](/atlas/)用于结构浏览。[成果中心](/results/)展示获准公开的科学数据包及其复现入口。[Explorer](/explorer/)将公开竞争记录与适用的最终资金证据关联。

[计算服务](/services/)接受范围明确的请求。更广泛的 Marketplace 仍在开发中，拟议产品另见 [Marketplace 路线图](/docs/marketplace/)。

## 本手册适合谁

**参与者**可以从[首次会话](/docs/quickstart/)开始，再了解模型存储、钱包和授权。**研究者**可以阅读模型、任务、验证和复现指南。**开发者与运营者**可以从架构和固定版本构建开始。**客户**应在提交范围说明前阅读服务请求指南。

阅读文档、浏览图谱或查看公开证据不需要钱包。打开页面不会开始仿真，也不会授权支出。

## 科学与网络范围

登记图包含 165,122 个神经元和 25,563,197 个有向神经元对。这是准备后的图规模；有向连接对并不是原始生物突触数量。模型使用确定性的整数点神经元动力学，具有明确假设，不能视为对全部生物动力学的实测重建。

已部署的钱包结算程序和 FBW 资产使用 Solana **Devnet**。最初两单位验收预算已完成。另一个总计 2 FBW 的任务供给阶段为两个新增校准目标提供预算，不改变原始已付款任务或供应量。主网、正式发行和生产付款未启用。当前边界见[功能可用性](/docs/availability/)。

## 项目与代币名称

官网界面名称是 **flybrainwork**。维护项目与 GitHub 所有者仍为 **flybrainlabs**。现有测试代币也名为 **flybrainwork**，符号 **FBW**，精度为八位小数。官网为 [flybrain.work](https://flybrain.work/)，项目 X 为 [flybrainwork](https://x.com/flybrainwork)。相同符号不能充分识别资产；完整 Devnet 身份见 [FBW Devnet 参考](/docs/devnet/)。
