# 科学模型

解剖来源是 **MaleCNS v1.0**，官方果蝇中枢神经系统连接组。flybrainwork 从该来源准备登记数值图，再执行冻结的整数点神经元模型。数据集解剖、数值假设与观测到的生物性能属于不同证据。

## 图与数据规模

| 项目 | 登记值 | 解释 |
| --- | --- | --- |
| 神经元 | 165,122 | 准备后的执行图节点 |
| 有向神经元对 | 25,563,197 | 有向连接对，不是原始生物突触数 |
| 图谱类型 | 11,751 | 解剖浏览使用的来源目录类型 |

| 基线范围 | 256 步 | 256 ms 数值轨迹；任务也可冻结其他范围 |

来源行可能包含分割片段和多次观测。请先阅读计数定义，不要将每一数据行都等同于一个生物细胞或突触。

## 整数点神经元 LIF 动力学

模型记录泄漏、输入累积、阈值事件、重置、不应期与连接传播。整数规则和冻结参数支持不同实现复算相同数值契约。

点神经元表示不求解树突分室。电流、膜状态和刺激成本使用**模型单位**，不是校准后的 mV、pA 或焦耳。递质到正负号的映射及相关参数选择包含假设。

登记图、参数、初始状态、时间步长和运行范围属于模型身份。即使页面名称不变，改变参数配置也属于不同科学计算。

## 配对 A/B 评估

A 与 B 使用相同模型、零初始状态和背景种子。B 添加候选刺激，A 作为对照。评估器在相对刺激结束定义的窗口内比较 B 减 A。

指标包括净目标事件、正响应细胞、非目标绝对变化、选择性与刺激成本。具体窗口、阈值和资格规则由冻结任务定义。本地非目标约束，包括 O32 范围，不能证明全脑副作用得到控制。

必需背景数量 R 描述数值契约，不是置信区间、参与机构数量或生物可重复性估计。

## 完整复算证明什么

完整复算证明提交输出在全部必需背景下符合冻结数值规则。原生、WASM 与 NumPy 字节一致说明测试实现之间可复现。二者都不能单独证明对活体的预测准确率。

外部验证需要获准观测、许可、冻结的校准与留出划分、合适指标和科学评审。这些仍是待完成事项；项目尚未发布确立的生物预测准确率。
