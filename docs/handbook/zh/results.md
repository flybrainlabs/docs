# 成果与复现

[成果中心](/results/)展示经过明确授权的科学公开成果，与 Explorer 的竞争和资金历史分开。公开校准示例可以有用、可复现，但不一定是当前轮次赢家。

## 按顺序阅读成果

1. 阅读目的与声明的科学范围。
2. 核对数据集、图、模型和参数身份。
3. 阅读刺激、对照与背景、时长和评估器。
4. 查看配对 A/B 指标及非目标范围。
5. 阅读验证证据、限制、来源与许可。
6. 查看允许下载的内容和主动复现入口。

## 科学身份

**SimulationID** 绑定数据集、图、模型、参数根、数值规则、初始状态、规范刺激、实际种子、步长与运行范围。钱包、文件名、展示标题、下游读出和外层轮次不属于该身份。

**ReadoutID** 绑定去重并排序的仿真集合、响应与非目标根、窗口、评估器和资格规则。它允许重新解释既有仿真输出，同时准确保留基础执行身份。

**ContributionID** 描述谁在任务、预算和授权下贡献了什么。**AcceptanceID** 记录独立冻结的验收判断和证据。这些身份避免循环定义和重复权益。

## 下载复现包

使用成果声明的下载链接。交付检查允许的文件、权限与到期时间、MIME、大小和 SHA-256。支持范围恢复的下载可以续传，无需再次传输完整文件。

保留清单，执行前核对下载摘要。阅读前提、模型范围和预期输出。复现可能需要完整模型和较多资源；浏览证据不会自动获取模型。

## 主动执行复现

复现是主动计算操作，不等同于选择历史观测。使用匹配模型和冻结参数，保留缓存，按包内契约比较必需输出。

成功复现证明该包的数值一致，不自动产生新发现权益、当前竞争胜利或外部生物准确性结论。

## 公开与隐私

私有候选、盐值、归档路径和客户工单不是公开成果。公开需要真实授权。公开投影或源码仓库不能用于绕过私有数据包访问控制。

公开计数按相关科学身份去重。下载量是下载事件，不是用户采用量；成果数不是活体独立实验数。
