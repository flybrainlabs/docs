# Explorer 使用指南

[Explorer](/explorer/)追踪公开科学竞争和资金证据，通过独立查询进程读取专门的公开投影。私有候选正文、盐值、客户请求、归档路径和签名材料不属于该投影。

## 选择需要的记录

从概览与轮次、候选链接追踪任务结果。轮次总结竞争，候选详情显示 claim、排序、验证与关联证据。有预算的 V3 候选还关联钱包、授权、永久单位、临时 Result 与最终付款。

项目 Explorer 与通用 Solana Explorer 不同。项目页面解释任务和 claim 的语义关联，再通过 Solana 链接检查确切链上操作及集群。

## 按顺序阅读证据

1. 检查任务、轮次和冻结科学身份。
2. 检查候选是否合格并完成提交。
3. 阅读完整复算证据和获准验证范围。
4. 阅读赢家判断与服务回执顺序。
5. 追踪经济单位与原受益人。
6. 阅读 Result 状态与 finalized 付款证据。

科学完成的候选仍可能在资金对账中。临时 Result 已关闭时，永久最终付款证据仍可以保留。

## 科学状态与付款状态

| 可见事实 | 解释 |
| --- | --- |
| 完整 / 达标计算 | 本地工作符合数值标准 |
| 验证通过的候选 | 全部获准复算接受候选 |
| 赢家 | 冻结竞争规则选中它 |
| 已预留 / 接受金额 | 存在有限资金义务 |
| 交易已提交或未知 | 仍需对账 |
| Finalized 已收到奖励 | 真实资产证据确认到账 |
| Result 已关闭 | 按政策关闭临时存储，付款唯一性仍保留 |

吞吐量、仅完成任务或未最终确认的签名不能证明奖励到账。

## 分页、时效与故障

历史浏览使用稳定游标。使用页面上下页控制，不应从客户端时间重建顺序。日期字段与回执序号是不同值。

查询或 RPC 失败不得用无证据的否定覆盖已信任的最终数据。没有 RPC 响应不证明付款或账户从未存在。查看时效和错误并重试读取；资金对账保留原业务身份。

公开投影可能落后于任务服务或 finalized 链状态。对照证据与更新时间，不应将临时展示差异解释为另一笔付款。

## 分享与隐私

讨论结果时分享公开轮次、候选 URL 和交易签名。不要在公开支持消息中提供私有回执令牌、盐值、客户原始数据或会话凭据。

科学公开包见[成果与复现](/docs/results/)，固定程序、mint 与已完成回执见 [FBW Devnet 参考](/docs/devnet/)。阅读 Explorer 不发起计算、出资或结算。
