# 故障排查

选择适合失败阶段、影响范围最小的恢复操作。调查时保留完整模型缓存、保存成果与公开标识。图形、存储和 RPC 故障具有不同原因。

## 准备没有进展

确认当前是下载、完整性检查还是构建。记录传输字节、日志中的资源或摘要、浏览器版本与可用存储。检查连接并重试受影响资源，不要立即重新下载全部数据。

配额错误时停止添加工作，保留或导出可用记录。隐私浏览或不同配置可能访问不到旧缓存。下载完成不代表构建完成。

## 挖矿显示等待

最初 Devnet 验收计划已完成。任务供给修订 3 在独立 2 FBW 阶段开启两个校准目标。刷新一次读取当前部署与预算；钱包已有权限和模型缓存保留。旧页面检测到阶段变化时，会向实时网关核对公开预算，同时保留固定资产、角色和权限默认值。

将空队列判断为网络故障前，检查任务服务实际状态。若供给耗尽且无开放轮次，需要另一个预先校准并提供预算的计划。钱包签名或存款不能重开已付款单位。

**模型已准备**描述本地准备，**没有开放任务**描述服务供给，二者可以同时成立。选择**检查新任务**刷新可用性。任务准入前，真实本地速率是**未运行**，不应将候选计为实际计算尝试。

存在准入任务时，核对模型就绪、钱包登录、授权、账户与世代，以及真正冻结的单位。不要复用已解决任务 ID，也不要将部分工作当成完整工作。

## 模型准备好，但没有线程计算

**请求 1 · 已准备 1 · 计算中 0**表示一个线程已加载模型，不表示钱包具有启动候选的权限。目标开放与线程空闲可以同时出现。

主控件指出下一准入步骤。连接、登录、科学任务与有限租金权限分别检查：

| 显示状态或操作 | 含义 | 下一步 |
| --- | --- | --- |
| **登录** | 钱包已连接，但无当前网站登录 | 审阅登录消息 |
| **检查钱包状态** | 余额与授权尚未同步 | 重试读取，不触发计算或转账 |
| **审阅租金授权** | 无可用授权，或余额、单次限额不足 | 审阅有限额度，愿意继续时主动确认创建或续期 |
| **更新设备授权** | 有授权，但当前设备没有不可导出签名密钥 | 在当前设备主动续期；连接恢复不从其他设备导入授权密钥 |
| 带预算说明的**检查新任务** | 当前轮次无可用冻结奖励单位 | 检查公开计划和实时网关，存款不能补出缺失奖励预算 |
| **开始挖矿** | 可见检查允许尝试启动 | 点击后再次核对实时预算、实际租金和设备密钥，再派发 Worker |

打开审阅不会签交易、变更授权或启动 CPU。取消保留准备模型和成果。成功授权后也不会自动开始计算，请主动选择**开始挖矿**。

再次失败时，展开**技术诊断**并报告准确文字、时间和可见钱包状态。网络、存储、模型锁和预算错误有不同解释。通用错误不能确定根因；缓存地址、模型就绪和任务查询 404 不能证明钱包授权或真实计算。

## Claim 查询返回 404

Claim 接口读取已存在提交，不提供新任务。`NOT_FOUND: claim` 表示响应服务没有找到对应 claim。服务健康和任务供给需分别通过签名当前轮次与就绪响应核实。

服务器接受承诺前，浏览器可能已保留候选和计算出的 claim ID。签名轮次已关闭、期限已过且无接受回执时，网站标记**轮次已关闭 · 候选未准入；成果已保留**，停止自动轮询，同时保留身份、指标和可下载输出。带回执的 claim 缺失、轮次开放或传输错误仍需对账，不会被当成已完成提交。

## 3D 空白或缓慢

重试图形或关闭图形，保留计算控件。用[神经元图谱](/atlas/)作结构对照，并记录 WebGL 是否可用、显示资源错误和图形模式。图形失败不要求清空完整模型缓存。

安卓真机显示和计算与图形并行，需要真实设备验收。图谱成功可帮助定位，但不能代替完整挖矿验收。

## 钱包已连接，但无法挖矿

连接、登录、有效有限授权和可用预算目标是独立要求。查看显示的账户、登录状态、grant 到期、剩余额度、成果数量及计划。授权审阅与计算开始都需主动操作，不能用缓存地址替代授权。

账户切换产生新授权上下文；旧结算属于原钱包。请检查原账户历史，而不是期待新钱包收到该奖励。

## 刷新后又要求连接钱包

网站请求钱包静默恢复已有权限。无法恢复时，解锁扩展、确认它支持 Solana Devnet Wallet Standard，并重新连接一次。保持同一浏览器配置，允许网站存储。网站登录过期要求重新登录，而不是再次选择钱包；主动退出则故意停止自动恢复。

临时节点错误可能延迟余额同步，但不会丢弃有效连接或登录，也不能证明存款或授权失败。未经钱包确认的保存地址不会显示为授权连接。

## 交易状态未知

保留原公开签名、业务或单位 ID 和受益人，重试读取可信证据。RPC 超时、历史缺失或 blockhash 到期不能单独证明失败。再次操作前，持久对账必须确认原动作是否执行。

临时 Result 关闭可以与永久单位已付款并存。文档关闭案例没有重复奖励或租金。[Explorer 指南](/docs/explorer/)说明如何追踪永久证据。

## 成果只出现在部分页面

本地历史、私有已接受候选、获准公开成果和公开投影范围不同。本地保存不是服务器接受；私有 claim 不会自动公开，投影也可能延迟。

比较 ID 与可见状态。成果中心提供获准复现包，Explorer 提供竞争与付款证据。不要上传私有盐值或工单凭据来说明差异。

## 提交有用报告

通过[联系与请求](/services/request/)提供操作、当前阶段、准确错误、浏览器与设备、时间、公开任务或候选或签名，以及针对性重试后是否重复。截图可说明布局，同时附上可读错误文字。

公开报告不包含钱包备份、私钥、签名会话材料、客户输入或私有回执令牌。恢复操作保持明确，避免重复已完成付款或发行。
