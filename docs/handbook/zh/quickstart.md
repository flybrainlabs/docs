# 开始您的首次会话

有用的首次会话从了解当前任务供给开始。即使某个预算阶段已经完成，也可以准备模型；但准备模型不会创建新的有奖励任务。期待奖励前，请先查看挖矿页面和[功能可用性](/docs/availability/)。

## 选择起点

| 您的目标 | 从这里开始 | 下一步 |
| --- | --- | --- |
| 了解项目 | [项目概览](/docs/overview/) | 阅读系统图和模型指南 |
| 探索解剖结构 | [神经元图谱](/atlas/) | 搜索类型、选择代表性神经元并阅读来源 |
| 查看既有成果 | [Explorer](/explorer/) 或[成果中心](/results/) | 追踪候选或复现包 |
| 准备计算 | [挖矿](/mining/) | 阅读准备状态和存储要求 |
| 请求限定范围的工作 | [计算服务](/services/) | 描述范围并取得私有工单 |

## 准备浏览器

使用支持 WebAssembly 和 Worker 的浏览器。流程依赖持久化浏览器存储，以复用模型数据块并保留成果。普通浏览和隐私、无痕会话的持久化能力可能不同。返回保存的工作时，请使用同一浏览器配置。

打开[挖矿](/mining/)，先通过主按钮连接钱包并完成登录，再查看任务、模型准备和预算状态。准备与计算都是主动操作。等待校验下载和模型构建完成；保留缓存有效时，访问其他页面后返回无需重新下载完整模型。

:::diagram preparation

进度显示跟随当前阶段。下载时查看已传输字节和完整性检查；构建时查看模型构建；挖矿时查看候选进度和实际吞吐量。仅下载完成不代表可执行模型已准备好。

## 有预算工作的钱包准备

有可用预算计划时，连接兼容的 Wallet Standard 钱包、确认账户、完成登录并审阅有限授权交易。这些步骤分别具有不同权限。批准交易前，请阅读[钱包连接与登录](/docs/wallets/)以及[授权、租金与退款](/docs/grants/)。

最初验收计划已完成。单独的 2 FBW 用户任务供给阶段准入两个新增校准目标。刷新挖矿页面读取当前目标和预算；账户没有可用额度时，再审阅有限授权。已有钱包权限与模型存储会保留；打开页面不会开始计算。存入本金不保证赢得任务。

## 计算期间

保持页面可用，根据设备调整线程和图形设置，并查看真实工作计数。需要降低活动时可暂停。适当保存或导出可恢复成果。中断的部分背景计算不等同于完整候选。

候选依次经历本地达标、提交、验证和赢家选择。只有 finalized 结算证据确认后，钱包奖励才算实际收到。[挖矿流程](/docs/mining/)按顺序解释这些状态。

## 保存有用记录

记录任务或轮次 ID、候选 ID 和公开交易签名。将导出包保存在您控制的位置。公开成果包声明范围和校验摘要；私有浏览器记录应保持私有，除非您主动选择分享。

失败时，请先使用[故障排查](/docs/troubleshooting/)，再决定是否处理存储。包含浏览器版本、失败阶段、公开标识和可见错误的报告，比单独的等待动画截图更有用。请勿附上助记词、私钥或会话凭据。
