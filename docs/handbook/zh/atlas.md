# 神经元图谱

[神经元图谱](/atlas/)是覆盖 **11,751 种来源类型**的结构浏览工具，帮助将任务目标和解剖标注与官方代表性骨架关联。普通浏览加载显示资源，不下载完整执行模型。

## 查找类型

可按类型名、别名或 FlyWire 名称搜索。来源有相应字段时，目录支持解剖区域、ROI、预测递质、超类、两性差异和侧别过滤。预期类型消失时，先重置过于严格的过滤条件。

选择类型更新代表性视图和资料。分页限制可见目录，详情解释来源标注。已收录的连接伙伴可指向另一本地类型；其他伙伴可能链接官方来源。

## 阅读代表性视图

每个类型具有来源确定的代表性骨架和 body ID。视图不包含该类型的每个细胞。缩略图来自真实骨架几何，不复用占位形状。

指针旋转、滚轮或双指缩放，使用支持的键盘控制、重置或自动旋转。上下文含官方中央脑、左右视叶和腹神经索外壳。这些表面不是带翅膀和腿的完整果蝇外形。

共享上下文和骨架坐标使用一致显示映射。聚焦模式框定选中神经元，全 CNS 模式保留空间背景。

## 谨慎解释标注

| 标注 | 如何理解 |
| --- | --- |
| 预测递质 | 来源预测，应查看不确定性 |
| 细胞数量 | 来源范围，可能包含侧别统计 |
| ROI | 描述解剖覆盖的感兴趣区域 |
| 上游 / 下游伙伴 | 来源连接摘要，不是实时因果实验 |
| 代表性 body | 显示形状使用的具体重建 |
| 两性差异 / 分类 | 来源标注，具有自身完整性与假设 |

描述由标注机械生成。不能仅从分类名称推断观测行为。突触位点、解剖接触和准备图中的有向连接对属于不同测量。

## 已知来源例外

收集时，**VP2_adPN** 的合并页和右侧页返回 404；登记的左侧页可用，提供代表性 body **10736** 和有限详情统计。整体类型数量仍来自目录，并注明详情范围。

另一个名为 VP2+_adPN 的类型未被用作替代。完整目录覆盖不代表每种类型都有双侧详情统计。

## 将解剖与计算关联

通过相关响应证据与[成果中心](/results/)，将 body 或任务关联到数值记录。解剖、实时观测和历史采样保持独立。选择类型不会自动仿真或上传本地历史。

3D 失败时，保留错误并使用目录资料，参照[性能与图形显示](/docs/performance/)。即使模拟布局通过，安卓真机验收仍待完成。
