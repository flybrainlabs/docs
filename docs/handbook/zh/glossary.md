# 术语表

阅读任务、计划或回执时，可对照这些解释。术语可能识别精确协议对象，但不证明所有部署或业务流程均已激活。

## 科学与计算

| 术语 | 通俗含义 |
| --- | --- |
| Connectome / 神经连接组 | 特定来源的解剖神经连接地图 |
| MaleCNS | 登记果蝇 CNS 解剖使用的来源数据集 |
| 有向神经元对 | 准备图中两个节点间的有向连接，区别于生物突触数 |
| LIF | 含泄漏、积分、阈值发放、重置和不应期的点神经元动力学 |
| 模型时间 | 仿真时间坐标，与现实执行耗时分开 |
| 背景 | 任务要求的冻结对照或输入环境 |
| A/B 运行 | 相同模型、背景的配对对照与刺激执行 |
| 读出 | 用窗口和评估器解释仿真输出 |
| 非目标变化 | 任务范围内目标集合之外的响应，不自动代表全脑副作用控制 |
| 校准 | 用来在参与前冻结任务或难度规则的测量 |
| 留出集 | 留给评估而不用于调参的数据 |
| SimulationID | 基础执行输入与范围身份，不含钱包、标题、读出 |
| ReadoutID | 对去重仿真记录进行指定解释的身份 |

## 竞争与证据

| 术语 | 通俗含义 |
| --- | --- |
| 任务 | 冻结模型、输入、评估器和验收定义 |
| 轮次 | 该任务的竞争时间表和提交流程 |
| Candidate / claim | 有原始身份与回执排序的提交尝试 |
| 承诺 | 私有候选完整揭示前提交的绑定记录 |
| 揭示 | 按轮次规则与承诺核对的披露 |
| 完整复算 | 真正执行全部必需背景并比较提交结果 |
| 任务服务回执序号 | 最早合格验证赢家规则使用的服务器顺序 |
| 公开投影 | Explorer 读取的刻意受限公开记录集 |
| 公开 | 暴露科学数据包的明确许可，与私有接受分开 |
| ContributionID | 任务、预算与授权下贡献类别的身份 |
| AcceptanceID | 独立验收判断、政策与证据的身份 |

## 钱包与资金

| 术语 | 通俗含义 |
| --- | --- |
| Devnet | 既有 FBW 验收使用的 Solana 测试集群 |
| Genesis | 区分目标集群的网络标识 |
| Mint | 精确代币账户与程序身份，符号不足以识别 |
| Atom | 最小代币单位；1 FBW = 100,000,000 atoms |
| Lamport | 最小原生 SOL 单位；1 SOL = 1,000,000,000 lamports |
| SIWS | Sign-In With Solana，证明账户控制权的限定消息 |
| 钱包世代 | 隔离账户与会话变更的单调授权上下文 |
| Grant / 授权 | 有明确限额的链上授权和 Result 租金本金 |
| 发现单位 | 固定金额、永久唯一的可付款任务槽位 |
| Result | V3 规范的 1,024 字节临时链上结算摘要 |
| 租金本金 | 指定账户所需原生 SOL，与奖励和网络费分开 |
| Finalized | 报告已收到付款要求的链确认等级 |
| 未知交易 | 需要对账的资金操作，不等于确定失败 |
| Outbox | 与业务协调、用于安全重试的持久传输记录 |
| 已接受负债 | 按实际验收规则确立的义务 |
| 权益 | 冻结合同或份额政策下的稳定受益权 |
| 未使用本金 | 授权下尚未消耗的存入金额，区别于已付租金 |

## 存储与开发

| 术语 | 通俗含义 |
| --- | --- |
| OPFS | 受支持浏览器保存网站持久数据的来源私有文件系统 |
| 快照 | 声明完整步边界上的兼容保存状态 |
| Manifest / 清单 | 验证构建或数据包的有序身份与内容说明 |
| 组件映射 | 每个组装文件与所属仓库的对应关系 |
| 固定发布 | 由 infra 修订和精确依赖提交识别的构建 |
| 工作树组装 | 明确验证本地修改的构建，不是已发布固定版本 |
| SBF | Solana 程序构建、执行格式，用于真实本地银行与 Devnet 检查 |
| SPL | 实际资产转账所需 Solana 代币程序集成 |
| Ridge | 需要真实数据和评估的拟议正则化线性模型训练路径 |

已部署、测试限定或待完成概念见[功能可用性](/docs/availability/)。
