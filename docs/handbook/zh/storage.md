# 模型缓存与恢复

浏览器保存经过校验的模型资源和科学记录，以便后续复用。它们有不同用途和生命周期：模型数据块是可复用输入，候选输出是某次计算的证据，快照则是恢复检查点。

## 保存哪些内容

| 对象 | 用途 | 重要边界 |
| --- | --- | --- |
| 已校验资源块 | 避免重复完整下载 | 必须符合预期摘要与资源身份 |
| 构建后的模型 | 高效准备执行 | 必须符合图与参数根 |
| 背景 / 成果记录 | 保存真正完成的工作 | 保留原始范围和数值字节 |
| 待交付输出 | 恢复未完成的本地交付 | 持久化不代表服务器已接受 |
| V3 快照 | 恢复兼容计算状态 | 必须符合完整步边界与身份 |
| 钱包 / 会话状态 | 限定浏览器操作权限 | 与科学成果及经济受益人分离 |

持久化使用浏览器提供的能力，包括受支持环境下的 Origin Private File System（OPFS）。存储属于网站来源和浏览器配置。不同浏览器、配置或来源不会自动共享同一存储位置。

## 下载完整性与复用

资源缓存键包含预期摘要，防止旧缓存冒充新资源。准备流程保留必要的全量完整性校验和分块检查。复用已验证模型不免除校验，只避免再次获取相同成功输入。

摘要不一致时，应识别具体资源和预期版本。正确修复是针对该资源检查并重试；清空全部模型和成果不是默认恢复操作。

## 保存、导出与恢复

需要便携记录时，主动使用保存或导出。保留数据包及声明的任务、模型身份。快照描述实际完成的步边界，部分缓冲区不是完整科学成果。

仅恢复兼容快照。模型、数值契约或任务不一致时，保留历史记录并开始新的兼容路径，不能静默重写身份。查看历史只读取已保存观测，不会自动开始新计算。

## 浏览器存储限制

配额取决于浏览器、设备和可用磁盘。隐私浏览结束后可能删除数据。浏览器清理工具或系统存储压力也可能移除网站数据。获得持久存储权限不等于为全部记录创建备份。

配额不足时，停止添加工作、保留当前证据，并尽可能导出可恢复记录。调整线程或重试准备前，先阅读错误和可用空间。重复完整下载可能进一步加剧问题。

## 本地恢复与服务器归档

浏览器缓存和任务服务私有归档是独立系统。本地输出可能等待上传；已保留的服务器 claim 可能等待验证或资金对账。通过标识比较两边状态。

云端备份、重启和合成浏览器恢复检查已在文档范围内通过。特定用户安卓真机存储恢复和完整灾难恢复演练仍需单独验收。见[运维与恢复](/docs/operations/)。
