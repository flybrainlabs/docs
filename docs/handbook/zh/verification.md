# 完整验证

验证将提交的科学输出与规定模型、任务的真实完整复算比较。它是范围明确、信任明确的数值完整性过程。链上交易不能替代复算。

## 必需的完整工作

验证器在准入前检查图、模型、参数、评估器与背景。它执行要求的范围，并按冻结契约比较原始数值记录。

科学投票前必须完成全部必需背景。缺失背景、原生进程中断或模型不可用，不能作为候选科学无效的证据。

响应记录、任务身份和归档承诺保留原始字节。显示采样帮助解释结果，但验证使用完整范围。

## 结果与故障

| 结果 | 含义 | 合适处理 |
| --- | --- | --- |
| VALID | 全部必需复算与候选一致 | 按获准验证政策计票 |
| INVALID_RESULT | 完整复算确定数值或契约不一致 | 记录科学拒绝及证据 |
| LOCAL_MODEL_ERROR | 本地模型不可用或错误 | 修复或隔离本地配置，不投科学否决票 |
| RETRYABLE_INFRA_ERROR | 执行或传输依赖失败 | 持久化、重试并保留原候选 |

文档中的验收对故意损坏的响应字节执行了新的完整复算，实际执行后返回 INVALID_RESULT。它比将基础设施故障制造成无效结果提供更充分证据。

## 用户参与与任务政策

FBW 用户自愿参与验证，成员可随用户加入或退出而变化。每项任务记录适用的准入规则、证据要求与结果判定政策。

参与者维护登记的完整模型，执行全部必需背景，并签署绑定任务与结果的报告。验收前核对身份、数值一致性与任务资格。当前参与路径见[功能可用性](/docs/availability/)。

## 证据类别

| 证据 | 可以证明什么 |
| --- | --- |
| 冻结来源 / 参数摘要 | 声明了哪些数值输入和规则 |
| 原生 / WASM / NumPy 一致 | 被测试实现间的复现 |
| 获准的完整复算 | 指定候选与全部必需背景的一致性 |
| Finalized Solana 回执 | 指定集群上的确切资金操作 |
| 获许可外部观测评估 | 已定义科学评估范围内的预测性能 |

计算可复现性说明登记模型内的数值一致性。与生物现象的比较采用单独获许可的观测资料、明确的校准流程和留出评估协议。

## 验证成本与报酬

复算消耗真实计算、存储和传输。验证服务合同可预留有限预算，冻结条款允许时，也可为正确拒绝付费。线程数、运行时间和报告吞吐量不是独立报酬单位。

归档保留与资金结算有各自义务。科学终态不停止已接受资金的对账，关闭临时 Result 不删除永久付款唯一性。
