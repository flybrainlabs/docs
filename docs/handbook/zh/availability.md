## Devnet 上的 Wallet Mining V3

Wallet Standard 界面、绑定来源的登录、有限授权、持久化资金意图、原子 Result 创建与付款以及历史记录均已实现。公开 Devnet 验收在同一授权下完成两个不同的完整模型赢家，各支付 **1 FBW**。

初始两单位验收计划已完成。单独的 **task-supply-20261013-v1** 阶段为两个从未使用、预先登记并校准的完整模型目标提供预算：**每个 1 FBW，共 2 FBW**。科学计划修订 3 开启第 32 轮并排队下一个目标。实时可用性以挖矿页面为准；对应冻结单位只能支付其验证通过的赢家。有限阶段完成后，模型准备、钱包历史和适用的未使用本金提现仍可使用。

第一个专用 Result 在归档认证后已关闭；第二个仍可读取。永久付款证据防止已关闭的 Result 触发重复付款或重复租金扣款。公开回执见 [FBW Devnet 参考](/docs/devnet/)。

## Marketplace 与未来网络功能

拟议目录、草案价格模板、迁移和只读目录 API 已实现。主机测试过的资金基础模块约束有限额度、账务和领取。原生服务 Worker、真实 Ridge 训练与导出、服务 SBF/SPL 集成、有限付费 API、结算退款和历史权益领取仍未完成。

可安装的开放验证者、非固定域名准入、质押和独立多运营者参与仍为后续工作。主网、正式生产发行与客户付款路径未启用。前提见 [Marketplace 路线图](/docs/marketplace/)和[经济模型](/docs/economics/)。

## 如何理解状态

数值复算确认声明的模型计算；浏览器测试确认被测试的交互或布局；finalized 链上回执确认对应资金操作。物理设备和外部科学结论各自需要真实证据。每篇指南明确这些范围，便于判断某个结果实际证明了什么。

## 社区参与

Social 提供登录钱包挑战、X 公开证据验证、持久化人工审核、社区积分和实际排行榜。公开预算属于准备范围：没有启用代币转账或即时领取。官方 OAuth、真实扩展钱包和真人 X 确认需要单独验收。见[社区指南](/docs/social/)。
