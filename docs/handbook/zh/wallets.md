# 钱包连接与登录

官网的新 Solana 挖矿体验使用 Wallet Standard。顶部提供钱包入口，挖矿与账户页面显示相关授权和历史操作。公开阅读不需要钱包签名。挖矿主入口先连接、再登录；仅打开钱包选择器不会启动计算。

## 三种独立状态

| 状态 | 可以证明什么 | 不授予什么 |
| --- | --- | --- |
| 已连接 | 钱包提供所选公开账户 | 存款、授权或任意交易权限 |
| 已登录 | 一次性消息向网站会话证明账户控制权 | 无限资金权限 |
| 授权有效 | 链上授权允许明确受限的操作 | 无限租金、更改受益人或自动追加本金 |

已连接账户仍可能需要登录；已登录账户仍可能没有有效授权；有效授权也可能遇到计划完成或成果数量限额耗尽。

## 刷新与连接恢复

成功连接后，浏览器记住钱包名称和公开账户，并限定于测试网络及程序。刷新或访问另一个页面时，网站请求该钱包静默恢复既有连接。网站核对钱包实际返回的账户后才显示已连接；保存地址本身不代表连接。

同一标签页保留未过期的网站登录，并核对账户。恢复连接不请求签名，不创建授权，不存入 SOL，也不重启挖矿。登录过期时，钱包可以仍保持连接，但网站会要求重新登录。

钱包锁定、缺失或不再允许静默连接时，请解锁并选择**连接钱包**。延迟注册的钱包可以继续恢复，无需再次选择。选择**退出登录 / 断开连接**会清除连接偏好和本标签页登录，刷新后保持断开。账户变更使旧连接失效，已接受奖励仍属于原受益人。

本地存储只记住钱包名称和公开账户偏好。短期登录保存在标签页会话存储中；钱包私钥和授权签名密钥不会复制进去。浏览器禁止存储或换用另一配置时，恢复可能不可用，但不会因此删除科学模型与成果。

## 登录消息

服务器生成一次性 SIWS 挑战，消息绑定账户、来源、URI 和链。签名前请在钱包中审阅。过期或已使用挑战必须更新；修改可见标签不能让它重新有效。

浏览器还使用范围受限的会话授权。支持的浏览器密码学路径使会话密钥不可导出，并将其绑定到钱包世代。网站不会因此获得钱包私钥。

## 批准交易前

核对所选账户、Solana 集群、程序、授权限额和存入金额。登录消息签名和交易批准是不同操作。交易审阅应符合公开计划与 [FBW Devnet 参考](/docs/devnet/)。

不要只凭符号识别资产。当前代币是固定的 FBW Devnet mint；不同 mint 即使同名也属于不同资产。

## 切换账户与授权世代

账户变更隔离后续异步操作和历史视图。旧钱包或世代产生的响应不能为新钱包提供资金或修改其状态。已接受结算仍绑定原受益人。

切换钱包不会转移已经为其他钱包接受的奖励。为目标账户重新连接并登录；历史操作在当前视图缺失时，请检查原账户记录。

## 我的记录与本地历史

打开[我的记录与付款设置](/account/)查看账户范围内的工作、已接受贡献、挖矿授权与历史，以及适用的资产证据。本地计算链接打开保留的浏览器贡献记录，不自动上传。

本地计算、已验收贡献和已结算资产各自有不同证据。地址控制权绑定不会迁移历史受益人，也不会创建第二份权益。钱包变更后的对账应使用原身份阅读历史记录。

## 兼容性与验收

旧的本地 `fly1` 密钥库与新钱包流程隔离，不会静默导入为 Solana 钱包或用于 Devnet 资金授权。

使用模拟 Wallet Standard 提供方的 Chromium 检查和公开 Devnet 脚本签名检查已通过。真实扩展钱包确认仍待验收。扩展未提供必需标准功能时，请报告名称、版本和错误，不应认为浏览器测试已认证该扩展。

授权可使用哪些资金见[授权、租金与退款](/docs/grants/)；公开账户与私有凭据的隔离见[隐私与安全](/docs/privacy/)。
