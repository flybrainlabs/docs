# 集成原则

集成必须保留版本化身份、有限权限，以及读取与资金操作之间的区别。SDK 和审核过的公开配置提供基础模块。本指南说明职责，不承诺完整收费 Marketplace API。

## 从配置与身份开始

阅读当前审核过的部署描述符。计算匹配模型和任务根，资金工作匹配 cluster、genesis、程序、代币程序、mint、精度与政策。不能只根据符号部分匹配资产。

科学域和规范字节编码是兼容输入，不能原地翻译或归一化已散列对象。使用维护的协议编解码，而不是手工构造签名字节。

## 公开产品读取

产品界面包括公开成果与任务列表、详情、证据登记、请求和账户流程。Explorer 使用独立公开查询面。采用客户端和实际分页契约；缺失或不可用值保持不可用，不编造零计数。

公开读取不得需要私有归档路径或签名密钥。成果包具有自身交付权限、MIME、大小、摘要及到期检查。客户工单限定于回执和获准运营者。

## 挖矿与钱包写入

挖矿 V3 要求绑定来源的一次性登录挑战、限定会话和有限授权。钱包连接、网站登录、有效授权、可用预算单位是独立检查。

候选资金意图在科学承诺前持久记录并 finalized。回调、历史和出资都限定于钱包及世代。账户切换后，已接受结算仍绑定原受益人。

认证写入同时检查 CSRF 与精确来源。不能为了绕过配置错误，将允许列表扩大为带凭据的通配访问。

## 重试与幂等

重试保留相同科学和业务身份。持久保存原签名交易字节与 outbox 状态。RPC 或历史未知时保留原义务和授权上下文。

过期由区块高度决定，slot 是不同坐标。Blockhash 过期不能单独证明未执行。再次尝试资金操作前，需对账交易、永久业务记录及接收方证据。

临时账户关闭后，已接受 Result 或付款不能重新作为新单位。基础设施故障也不能成为科学否决票。

## 当前集成限制

钱包挖矿 Devnet 集成已实现，并有真实链上证据。真实扩展和物理设备需要独立确认。可安装的开放验证者与质押仍为后续工作。

Marketplace 有限付费 API、服务 SPL 适配器、真实训练模型交付与历史领取仍未完成。API 目录定义不授权向客户收费。选择集成目标时参阅[功能可用性](/docs/availability/)与英文维护[状态](https://github.com/flybrainlabs/docs/blob/main/docs/STATUS.md)。
