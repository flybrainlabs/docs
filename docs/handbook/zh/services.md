# 计算服务请求

[计算服务](/services/)接受范围明确的科学计算或交付请求。现有流程创建私有工单，将审核、方案、报价确认、预算、执行与交付分开。提交表单不是付费执行，也不保证某个结果。

## 描述有用请求

说明问题、目标模型或任务、刺激或目标范围、必需输出、期限，以及材料是否私有。声明允许的科学解释。例如数值响应比较与生物预测性能结论需要不同交付物。

支持的范围概念包括刺激搜索、响应比较、公开赞助、检索与交付。表单字段存在不意味着私有执行、任意参数扫描、多模型产品或未公开生物准确性自动可用。

不要提交可执行指令或秘密。客户文字作为数据处理，受限或敏感请求需要实际审核和合适授权。

## 请求生命周期

| 阶段 | 含义 |
| --- | --- |
| 已接收 | 校验请求持久保存，并发出私有工单 |
| 范围审核 | 运营者评估科学、许可、资源与隐私要求 |
| 方案 | 描述交付与验收标准 |
| 报价确认 | 客户审阅实际价格和条款 |
| 等待预算 | 等待明确资金与授权条件 |
| 执行中 | 执行获准工作 |
| 已交付 | 按合同交付约定材料与证据 |
| 已关闭 | 记录合同或工单关闭，同时保留必需义务 |

签名运营操作和客户确认记录状态转换。同一重试应复用幂等请求身份，不应再次生成购买。

## 报价与验收

报价应分别列明执行、复算、归档、传输、交易费、账户本金、存款与预付款，并注明资产、金额、受益人、资金来源与退款处理。

交付标准应注明模型、任务身份、完整运行范围、文件清单、摘要、所需复算及允许用途。文件按标准验收，目标指标不代表已实现准确率。

生产付款路径和正式资产未配置。目录价格草案不是已激活报价。见 [Marketplace 路线图](/docs/marketplace/)。

## 私有工单与公开

工单通过私有回执令牌和获准操作访问。请将令牌作为访问凭据保护。公开成果需要独立授权；工单不会自动发布到 Explorer 或成果中心。

没有真实隔离和访问控制，不承诺公开矿工上的保密执行。向获准运营环境外分派前，应解决许可和客户数据边界。

## 保留与支持

按文档请求政策，请求字段最长 **365 天**后删除。审计和合同保留另有披露要求。适用通知见[隐私](/privacy/)和[条款](/terms/)。

询问既有请求时，通过私有工单路径提供范围和状态，不公开回执令牌。也可使用请求页面提交不含敏感信息的产品诊断。
