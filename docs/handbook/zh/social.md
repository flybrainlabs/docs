# 社区贡献与 Social

[打开 Social ↗](/social/)以关联社区身份、完成验证贡献并查看真实排行榜。访客可阅读，参与需要登录钱包。

## 社区预算意味着什么

页面展示用于未来社区空投的 **25,000,000 FBW** 预算，来自既有 **31,183,323 FBW 社区与生态池**。剩余 **6,183,323 FBW** 保留用于其他社区、生态用途。

| 社区池内用途 | FBW | 占该池比例 |
| --- | ---: | ---: |
| 未来社区空投 | 25,000,000 | 约 80.17% |
| 其他生态用途 | 6,183,323 | 约 19.83% |
| 社区与生态池 | 31,183,323 | 100% |

“超过 80%”指该池，不是总代币供应。这是预算分配，不会创建新代币，也不表示代币已转出或锁入专用链上金库。既有 FBW 资产位于 Solana Devnet。

社区积分记录已验证贡献，并决定您的社区排名。

## 连接钱包并登录

使用网站共同的钱包按钮连接 Wallet Standard Solana 提供方，选择账户，再签署登录消息。连接账户和证明控制权是两步。登录是消息签名，不授权转账，也不需要网络交易费。

钱包支持时，刷新可以静默恢复已选择的钱包和账户。同一标签页保留匹配且未过期登录。钱包锁定、缺失或登录过期可能需要操作。主动断开后保持断开；切换账户会清除旧参与者私有视图。见[钱包连接与登录](/docs/wallets/)。

Social 不要求有效挖矿授权或未完成科学目标。社区积分与挖矿奖励分别记录，网站不会把代币余额当作社区得分。

## 验证 X 身份

首个任务是**连接 X 身份**，初始奖励 **10 社区积分**。每个钱包和已知 X 身份仅贡献一次。奖励由服务器定义，浏览器不能选择。

### 1. 生成验证帖子

登录后选择**开始验证**。网站生成绑定当前钱包和登录、有效 **30 分钟**的随机公开挑战。验证码以 `FBW-VERIFY-` 开头，并显示到期时间。

可选择中性身份声明或项目介绍并编辑文字。完整验证码必须放在**原帖正文**。奖励不随措辞、宣传语气或互动量变化，不要求正面背书，关注、点赞和转发不属于本任务奖励。

新挑战使旧挑战失效。使用当前码，不能使用截图或保存的旧文字。刷新同一已登录标签页可恢复有效挑战和提交 URL。

### 2. 在 X 发布

复制文字或选择**在 X 发布**，X 打开自己的发布界面，由您确认。网站不会代发，也不要求 X 密码、Cookie 或访问令牌。

验证期间保持帖子公开。私有或不可用帖子可能无法提供证据。验证码需直接位于您自己的正文；仅放在图片、链接、展示名称或引用帖子中不足以验证。

### 3. 提交帖子链接

返回 Social，粘贴 HTTPS X/Twitter status URL，选择**验证帖子**。后端读取官方公开 oEmbed 证据，检查真实作者与 status 身份，再查找原正文验证码。同时检查到期、会话控制、历史完成、已知身份冲突与帖子复用。

全部通过后，身份绑定、完成记录、积分和历史一并保存。页面显示**X 身份已连接**、获准奖励、更新总分和真实排名。已验证帖子与时间保留在“我的社区”；刷新读取既有结果，不重复奖励。

## 理解验证状态

| 状态 | 含义 | 合适操作 |
| --- | --- | --- |
| 可参与 | 尚未完成任务 | 登录后开始挑战 |
| 进行中 | 有有效挑战 | 发布验证码并提交 URL |
| 待验证 | 后端检查正在运行 | 等待；刷新可恢复状态 |
| 需要审核 | 可用证据或身份检查不足 | 保留原始证据供审核 |
| 已完成 | 贡献已记录 | 查看积分、排名和帖子 |
| 已过期 | 超过 30 分钟窗口 | 生成并发布新挑战 |

X 来源不可用、作者无法确认或原正文不完整时不产生积分，请求保存供审核。审核者需检查原公开帖及真实作者；仅在表单复制码不是证据。挑战或原登录会话过期时需重新挑战。审核拒绝会说明结果，并允许按任务规则重新尝试。

公开 oEmbed 建立 **challenge_verified** 控制权，不是 OAuth，可能无法提供稳定数字 X 用户 ID，该字段保持空。用户名可能变化或被重新分配，争议变更需审核。官方 OAuth 是未来身份升级。

## 积分与排行榜

每次积分变动都有来源和时间。成功完成追加一条贡献记录；纠正追加独立审计调整，旧记录保留。重试、点击或刷新不重复首奖。既有已得积分保留。社区 v2 升级将尚未完成的身份挑战调整为 10 分；之后的任务版本仍以创建挑战时的奖励记录为准。

排行榜使用有效正社区积分，分数高者在前。同分按达到当前分数的时间，再按稳定钱包地址排序。审核账户可暂时从公开排名排除，但账簿不删除。审核和纠正留下管理记录。挖矿吞吐量、质押和持币量不影响该榜。

使用**刷新**请求当前数据，或加载更多排名、活动。分页期间实时排名可能变化。可复现分配依据获批不可变快照，而不是后来任意截图。

## 每日签到

登录后选择**签到**。每个 UTC 日期可签到一次，获得 **1 分**，每日 **00:00 UTC** 重置。重复点击、刷新或重试读取同一条记录，不会重复奖励。“我的社区”和“活动记录”会显示实际总分与签到时间。

## 每日发 X 帖子

完成 X 身份绑定后选择**发布帖子**。生成当前 **FBW-POST-** 验证码，从已绑定的 X 账户发布包含验证码的公开原帖，然后粘贴帖子链接，选择**验证帖子**。每次成功 **+1 分**，每个 UTC 日期最多计 **3 次**。

每次贡献使用新的验证码和原帖。验证沿用身份绑定的官方公开证据与原作者检查。身份验证帖子、重复链接、历史帖子或其他作者均不能重复计分。验证码有效期为 30 分钟，或到当天 UTC 午夜，以较早者为准。验证来源失败进入原有审核流程，不消耗成功发帖名额。每日计数和上限由服务器执行，包括并发提交。

## 邀请好友注册

登录后选择**创建邀请链接**，链接在刷新后保持不变，并可复制分享。新参与者打开链接，在 Social 使用自己的钱包签名登录，首次社区注册时固定邀请归属。已经注册的用户不能重新归属；仅创建或打开链接不产生积分。

受邀新用户成功完成唯一的 X 身份绑定认证后，邀请人获得 **10 分**，受邀者另按正常绑定任务获得 **10 分**。重复验证、再次登录、已经获得首奖的 X 身份或重复钱包注册不会再次奖励。**邀请人数无上限**。邀请面板显示真实注册人数、认证人数与已获邀请积分。

## 排行榜隐私与布局

桌面端排行榜位于参与区域的**右侧**，窄屏采用单列。公开排名显示原长度的钱包地址，将正中间 **8 个字符替换为 <code>********</code>**。不提供复制钱包地址按钮，也不提供展示 X 用户名的设置。公开排行榜接口同样不返回完整钱包地址或 X 用户名。

您的 X 绑定信息仍只在登录后的个人资料中显示。验证帖子本身仍在 X 公开；公开贡献流省略会话、私有审核原因和管理员证据。

通过新的钱包登录可以解除 X 绑定。已得积分和首任务完成保留，每日发帖需要有效绑定。解除不允许重复首奖，也不允许其他钱包复用已知身份。

## 未来分配与管理

获准管理员可以审核原始证据、配置任务、追加积分纠正、标记账户争议和冻结排名。快照记录截止点、规则、积分、排名、资格与内容摘要，不可覆盖。纠正保留旧快照并创建获审计的后继版本。

候选分配使用选定冻结快照、明确有限预算和版本规则。当前准备引擎按合格积分比例分配精确整数 atoms，并按稳定排名处理余数。候选本身不预留资金。只有快照获批且规则公布后，内部审批才预留金额，所有获批预留计入 25,000,000 FBW 上限。取消追加释放记录，不删除历史。

CSV/JSON 导出是准备产物，不发送代币、不提供即时领取、不建立通用兑换率。实际未来转账需要单独获准的执行流程和验证链上证据。

## 常见问题

**为什么验证后代币余额不变？** 您得到社区积分；积分与 FBW 余额是不同记录。

**为什么显示需要审核？** 后端无法建立足够公开证据或解决身份冲突，不预设成功。

**解除绑定后能再次领取首奖吗？** 不能，历史完成和已知身份唯一性保留。

**为什么刷新要求登录？** 钱包仍可连接，但网站登录会过期。新签名证明控制权，不是转账。

**为什么没有排名？** 没有合格正积分的账户不排名，这是实际空状态。
