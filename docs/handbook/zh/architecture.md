# 系统架构

项目在 [flybrainlabs](https://github.com/flybrainlabs) 下维护十个仓库。每个组装源码文件只有一个所有者。发布由基础设施提交及精确依赖修订清单识别。

## 组件与职责

| 仓库 | 职责 |
| --- | --- |
| web | 产品界面、文档渲染、图谱与静态导出 |
| node | 任务服务、归档、完整复算协调与产品服务 API |
| miner | 原生 / WASM 数值核心、浏览器线程、存储和挖矿控制 |
| explorer | 公开投影、独立查询服务和记录界面 |
| protocol | 版本化科学、资金身份与回执基础模块 |
| contracts | Solana 程序与公开部署回执 |
| sdk | 编解码、钱包集成、客户端和持久传输 |
| research | 模型准备、任务定义、校准与评估 |
| docs | 英文维护文档、双语官网手册、协议说明和操作指南 |
| infra | 依赖固定、组装、部署与发布工具 |

**web 仓库为私有**，其余维护仓库公开。完整检出需要 web 访问授权，阅读官网不需要。

## 浏览器边界

网站提供原生 HTML 和同源资源。挖矿在 Worker 内运行 WebAssembly 数值核心并使用持久本地存储。钱包连接、登录和限定授权与模型准备分别处理。

阅读文档和历史不会自动开始仿真。文档搜索索引只含公开手册文字，不查询私有候选或工单。

## 任务服务与复算边界

任务服务管理持久科学排序、资格、候选归档与赢家选择。获准原生 Worker 复算必需背景。运营身份、模型文件、数据库与 WAL、私有归档保持在仓库及官网导出之外。

一台小主机可用三个身份顺序复算。这是资源安排，不是三个独立运营者的证据。

## 公开查询边界

Explorer 查询进程读取公开投影，不读取私有任务数据库。仅提供获准公开字段、稳定游标与证据链接。私有候选和客户请求不能通过该 API 获取。

## 链与资金边界

V3 扩展封装明确版本化的资金操作，保留旧指令标签、布局与签名域。永久单位、意图记录保持资金唯一性。对已接受可付款赢家，临时 1,024 字节 Result 与精确代币付款原子创建。

中继传输有限签名操作，并持久对账未知结果。科学终态不会丢弃待处理资金负债。程序升级与 Result 关闭信任仍属于获准项目钱包。

## 兼容与构建边界

部分内部 crate 名称、schema 字符串、种子域和存储键保留历史 `flypow` 标识。这些是兼容字节，不是当前展示品牌。品牌修改不得改变科学摘要、地址或历史签名。

组装器保留这些输入的跨组件路径。可复现检出见[构建与贡献](/docs/development/)，保留状态的发布见[运维与恢复](/docs/operations/)。
