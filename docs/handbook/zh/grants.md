# 授权、租金与退款

挖矿授权（grant）是有限权限和原生 SOL 本金账户。它允许协议为合格获胜单位创建必要的 Result 账户，无需为每个候选再次请求矿工签名。限额被冻结并在链上执行。

## 您需要审阅什么

授权固定矿工与奖励钱包、会话密钥、钱包世代、到期时间、单个 Result 租金限额、累计限额和成果数量。它不授予任意交易或 CPI 权限，不允许自动追加本金或更改受益人。

存入的是**用于允许的 Result 租金的 SOL 本金**，与 FBW 奖励分开。授权管理租金、中继交易费和辅助账户各有声明的出资责任。存款不属于服务收入，也不保证收益。

## 何时消耗租金

对于可付款赢家，最终操作验证授权，只扣除实际缺少的 Result 租金，写入规范的 **1,024 字节 Result**，将固定 FBW 金额转入原钱包代币账户，并将永久单位标记已付款。业务效果原子完成。

最终操作失败会回滚这些业务效果，网络交易费仍是单独可观察的成本。重复已付款单位不会创建第二次奖励或第二次租金消耗，包括临时 Result 已关闭之后。

1,024 字节是 Result 账户数据大小，不是完整科学归档、交易包或总运营成本。

## 续期、重绑定与撤销

续期或资金重绑定需要原矿工的交易授权。它保留原科学 claim、已接受受益人、经济唯一性和可付金额，不能将旧工作变成新发现单位。

撤销明确终止授权对新操作的权限。适用提现将未使用本金退回同一钱包；已经用于已接受 Result 租金的本金不是未使用本金。

切换浏览器钱包不会改变原授权退款接收方。使用操作前，始终审阅所属账户与世代。

## Result 关闭与归档证据

项目签名者只有符合规定保留期和归档证书规则时，才可关闭合格的临时 Result。租金退给固定项目接收方。这不会关闭永久付款证据，也不会补回矿工已消耗本金。

归档认证与链上关闭不等于删除科学历史。记录中的验收保留了第二个 Result，并在归档核验后关闭了专用的第一个 Result。

## 当前有限计划状态

最初授权存入 23,408,640 lamports，为两个 Result 消耗 11,704,320。显式撤销后，退回未使用的 11,704,320 lamports。该次验收中，每个实际 Result 租金为 5,852,160 lamports；后续租金必须依据当前报价及冻结限额。

这些数值描述已完成的最初 Devnet 验收。单独的任务供给阶段预留两个新增、各 1 FBW 的单位。存款前阅读账户实际授权审阅；新任务预算不会增加您已签署的支出或成果数量限额。在相同 genesis、程序和政策下，已有可用权限可以继续有效。两个阶段及最终预算回执见 [FBW Devnet 参考](/docs/devnet/)。
