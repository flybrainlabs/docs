# Marketplace 路线图

规划中的 Marketplace 将验证计算转为可复用产品，采用不可变版本、有限 API 权限和可对账结算。它比 Wallet Mining V3 涵盖更多业务；一次 Devnet 发现奖励不代表 Marketplace 已完成。

## 拟议目录

目录将响应、刺激搜索、干预、光流、逼近、朝向、气味、异常、导航和稀疏检索十个研究项目归为五个产品系列：

| 系列 | 拟议范围 |
| --- | --- |
| FlyBrain Core | 分别提供缓存访问、完整复算和有限目标搜索 SKU |
| FlyMotion-Lite | 轻量运动与光流读出 |
| FlyHeading-Lite | 朝向相关读出 |
| FlyOdor-3 | 气味相关读出 |
| FlySparseSearch | 稀疏检索与搜索 |

名称描述拟议产品，不代表已完成训练模型。不同 Core SKU 不会将同一底层计算变成三个独立训练模型。

十项目、五产品目录、八个草案价格模板、追加式迁移和只读目录 API 已实现。实际成本、基准和明确激活完成后，价格才能成为报价。

## 必需的完整闭环

:::diagram marketplace

获准完整模型工作必须生成真实训练数据。小型 Ridge 模型必须真实训练、评估，并导出全部权重、偏置和归一化；随后冻结不可变版本与贡献者份额清单。

有限服务授权支付一次真实调用。只有交付、结算且成熟的收入产生历史权益，由原贡献者领取。第二次真实调用可在没有新挖矿时生成新收入；同一次调用重试不能重复收费、退款、分配或领取。

## 科学训练要求

输入不能读取要预测的响应。训练、验证和测试应按底层轨迹划分，避免相关样本泄漏。分布式 Ridge 合并充分统计量，不合并独立训练权重矩阵。

受控分片重算检查覆盖与矩阵完整性。目标指标和实测性能分别记录。原生工作在 SQLite 锁和 HTTP 执行线程之外进行；标记完成前必须成功持久写入真实产物。

## 资金与存储要求

拟议 API 支付资产是 **FBW**，生产身份与获取路径未配置。现有 FBW Devnet 资产是测试资产，不支付生产服务。

已测试服务域约束完整资产身份、有限额度、请求幂等、累计池与领取、退款上限及共享金库覆盖。金库必须覆盖客户、预留、未成熟、退款、任务与未付收入义务总和。

完整小模型存储需要真实内容、顺序、长度和引用。只有摘要的清单不代表完整模型已上链；混合存储需明确标注。

## 剩余实现

仍需独立服务 SBF 适配器和真实 SPL 集成、预算分派与租约隔离接口、原生 Worker、真实训练导出评估、不可变发布、有限 API 授权、持久结算和未知状态对账、退款、历史权益领取以及完整产品验收矩阵。

相关产品激活前需解决外部数据权利，包括尚未解决的来源许可冲突。导入目录定义不能创建 Worker、客户、收入、准确率或预算事实。当前范围见[功能可用性](/docs/availability/)。
