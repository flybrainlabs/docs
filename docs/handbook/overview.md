# Project overview

flybrainlabs produces verifiable, reusable computations over a fruit-fly neural connectivity graph. A browser can prepare the registered model, search a frozen stimulus task and preserve its output. An authority coordinates submission and complete replay. Public results and the Explorer make the resulting evidence easier to inspect.

The project combines scientific computation with a finite funding model. Every payable discovery belongs to a defined task and reserved budget. A successful numerical result, a competition win and a finalized token payment are separate events.

## Who this handbook is for

**Participants** can follow [Your first session](/docs/quickstart/), then learn about model storage, wallets and grants. **Researchers** can inspect the model, tasks, verification and reproducibility guides. **Developers and operators** can start with architecture and pinned workspace builds. **Customers** can read the service request guide before submitting a scope.

You do not need a wallet to read documentation, browse the atlas or inspect public evidence. Reading a page does not start a simulation or authorize spending.

## Scientific and network scope

The registered graph contains 165,122 neurons and 25,563,197 directed neuron pairs. These counts describe the prepared graph; directed pairs are not the original biological synapse count. The model uses deterministic integer point-neuron dynamics. It is a computational model with explicit assumptions, rather than a measured reconstruction of all biological dynamics.

The deployed wallet settlement program and FBW asset use Solana **Devnet**. The two-unit acceptance budget is complete. Further rewarded work requires new prospectively calibrated tasks and a frozen finite budget. Mainnet, formal emission and production payments remain inactive. See [Feature availability](/docs/availability/) for the current boundary.
